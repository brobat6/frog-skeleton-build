DEMO VIDEOS of animations + shaders can be found in the "demo_videos" folder.

Instructions to run the code:

Pre-requisites : Node.JS

- Open the current project folder in a terminal.
- Type "npx vite", and the local server will be created. Then website can be
    viewed on http://localhost:5173/.

In case there is an error, dependencies will need to be installed:
- In terminal (same project folder), type:
    - npm install --save three
    - npm install --save-dev vite

If there are still errors, delete package.json and package-lock.json and node-modules folder, and 
type the install commands again.

Installation instructions were exactly followed from https://threejs.org/docs/index.html#manual/en/introduction/Installation.
